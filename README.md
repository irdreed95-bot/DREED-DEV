# DREED DEV

Portfolio website for DREED DEV — web development, dashboards and custom digital solutions.

## Structure

- `index.html` — main portfolio page
- `styles.css` — responsive visual system
- `script.js` — menu, year and project request form
- `.github/workflows/pages.yml` — automatic GitHub Pages deployment
- `assets/favicon.svg` — site icon

## Before publishing

Open `script.js` and replace:

`YOUR_EMAIL@example.com`

with the email you want to receive project requests on.

## GitHub Pages

The repository includes a Pages deployment workflow. In GitHub, open:

**Settings → Pages → Build and deployment**

and select **GitHub Actions** as the source if GitHub asks for the Pages source.

After the first workflow run, the site will be available from the repository's **Deployments / github-pages** environment.

## Adding real projects

Replace the three sample project cards in `index.html` with real projects as they are completed. Add a live demo URL and, when useful, a GitHub repository link for each project.
